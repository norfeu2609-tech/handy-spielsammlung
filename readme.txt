# Handy-Spielesammlung

Kostenlose Lernspiele für Kinder - entwickelt für lange Autofahrten!

## Spiele
- 1×1 Training mit schriftlicher Multiplikation
- Kennzeichen-Finder
- Stadt-Land-Fluss
- Zahlenrätsel
- Geschichten erfinden (mit Aufnahme)
- und mehr!

## Nutzung
Einfach die Datei `handy-spielesammlung.html` herunterladen und im Browser öffnen.
Funktioniert komplett offline!
server_starten.py muss im selben Verzeichnis stehen, wegen der Aufnahme im letzten Spiel.
